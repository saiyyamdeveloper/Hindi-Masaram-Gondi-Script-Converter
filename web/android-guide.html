    • File Manager में TTF खोलो → Install, या
    • Settings → Display → Font में add करो (OEM पर अलग हो सकता है), या
    • सबसे आसान — इस Gondi font को HeliBoard/अपने App में bundle कर दो (Option B देखो)।
    बिना फ़ॉन्ट के गोंडी बॉक्स □ दिखेगी — converter सही है, सिर्फ़ display missing है।

    या manual: Settings → Advanced → Custom layout → Paste JSON → florisboard/layouts/characters/masaram_gondi.json की पूरी content paste करो।
    दोनों layouts अलग-अलग दिखेंगे:

2 · सबसे आसान — commit से पहले convert

import org.masaram.gondi.DevanagariToMasaramGondi

class GondiInputMethod : InputMethodService() {
    private val ic get() = currentInputConnection

    fun onHindiCommitted(hindi: String) {
        // “नमस्ते” → “𑴟𑴤𑴫𑵅𑴛𑴺”
        val gondi = DevanagariToMasaramGondi.convert(hindi)
        ic?.commitText(gondi, 1)
    }

    fun onWordFinished(hindiWord: String) {
        // smart-ra ON is default — कर्म/क्रम सही
        val gondi = DevanagariToMasaramGondi.convert(hindiWord, smartRa = true)
        ic?.commitText(gondi, 1)
    }
}

3 · Live-replace — current word को Gondi में बदलो

User ने पहले से “भारत” टाइप किया हो, cursor अंत में हो — back में scan करके आख़िरी देवनागरी शब्द को replace करो।

fun onUpdateSelection(...) {
    val before = ic?.getTextBeforeCursor(64, 0)?.toString() ?: return
    val pair = DevanagariToMasaramGondi.convertLastWord(before) ?: return
    val wordLen = before.length - pair.first
    val converted = pair.second
    // loop से बचो — यदि पहले से converted है तो दोबारा मत लिखो
    if (before.substring(pair.first) == converted) return
    ic?.deleteSurroundingText(wordLen, 0)
    ic?.commitText(converted, 1)
}

// convertLastWord(before, cursor) returns Pair(startIndex, gondiWord)
// isIndicRun = 0900..097F या 11D00..11D5F

4 · Halanta vs Virama — word-final case

// Virama 𑵅 (11D45) = conjunct former → हिन्दी में `्` जो conjunct बनाये
// Halanta 𑵄 (11D44) = voter killer → शब्द-अंत पर बिना conjunct के vowel मारे
DevanagariToMasaramGondi.convert("हिन्दी") // → 𑴬𑴲𑴟𑵅𑴝𑴳 (virama)

// यदि trailing hal dead consonant चाहिए:
DevanagariToMasaramGondi.convertWithFinalHalanta("हिन्द") // → ...𑵄 (halanta)

समस्या हल · Troubleshooting

□□□ दिख रहे हैं?

Font install नहीं / Keyboard ने custom font load नहीं किया। TTF reinstall करो या App में bundle करो। Web पर सही दिखे तो converter सही है।

HeliBoard import fail?

  • ZIP नहीं तो JSON सीधा paste करो (Custom layout → Paste JSON)
  • पुराना HeliBoard हो तो update करो — JSON schema बदला है
  • FlorisBoard v0.4 पर direct import नहीं — HeliBoard use करो या source build

Repha / Ra-kara गलत?

smart_ra = true default है। OFF करने पर कर्म = 𑴌𑴦𑵅𑴤 (गलत) vs ON पर 𑴌𑵆𑴤 (Unicode-correct)। हमेशा ON रखो।

Virama vs Halanta confusion?

Virama 𑵅 conjunct बनाता है (स्त), Halanta 𑵄 सिर्फ़ vowel मारता है। Word-final के लिये convertWithFinalHalanta() use करो।
