# Masaram Gondi — FlorisBoard / HeliBoard layouts

Poori **75-character** Masaram Gondi lipi ke do mobile layouts.

| File | Kab use karo |
|---|---|
| `layouts/characters/masaram_gondi.json` | Phonetic — FlorisBoard ke `hindi_in` jaisi jagah, Hindi typist ke liye |
| `layouts/characters/masaram_gondi_inscript.json` | InScript — physical InScript muscle-memory |
| `characters_75.json` | Saare 75 glyphs + decimal codes (reference) |
| `extension.json` | Extension metadata |

## Import

**HeliBoard** (recommended aaj ke liye): Settings → Languages → custom layout → JSON paste / import.

**FlorisBoard:** v0.4 me keyboard extensions abhi *partial* hain; v0.5 addons store ke liye yeh package ready hai. Tab tak files ko source tree me `org.florisboard.layouts/layouts/characters/` ke under rakh ke build karo, ya HeliBoard use karo.

Font: **Noto Sans Masaram Gondi** phone pe install karo, warna boxes dikhenge.

## Shift / long-press

Har key pe `upper` = Shift, `popup.relevant` = long-press.

- Virama `𑵅` (11D45) conjunct banata hai
- Halanta `𑵄` (11D44) sirf inherent vowel silent karta hai
- Repha `𑵆` / Ra-kara `𑵇` cluster-ra ke liye
